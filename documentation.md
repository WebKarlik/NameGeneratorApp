# Документация проекта

## Общее описание 
`NameGeneratorApp` - это Java-приложение с графическим интерфейсом (Swing), которое генерирует случайные комбинации имен и псевдонимов. Приложение позволяет:
- Генерировать случайные фразы (имя + псевдоним)
- Добавлять новые имена и псевдонимы
- Просматривать и управлять списками слов
- Сохранять историю последних сгенерированных фраз

### Основные методы
#### ```main(String[] args)```
Точка входа в приложение. Создает и запускает экземпляр приложения в потоке обработки событий Swing.
#### ```initialize()```
Инициализирует графический интерфейс:
- Загружает данные из файла
- Создает главное окно
- Настраивает панели и кнопки
- Добавляет обработчики событий
#### ```loadData()```
Загружает данные из JSON-файла (```data.json```):
- Читает файл с помощью JSONParser
- Восстанавливает списки имен, псевдонимов и последних фраз
- Если файл не существует, инициализирует стандартные значения
#### ```saveData()```
Сохраняет текущие списки имен и псевдонимов в файл ```data.json```.
- Каждый элемент массива на новой строке
- Отступы для вложенных элементов
- Поддержка кириллических символов
#### ```savePhrases()```
Сохраняет текущий набор сгенерированных фраз в файл phrases.json.
#### ```generatePhrase()```
Генерирует случайную фразу (имя + псевдоним):
- Выбирает случайное имя и псевдоним
- Добавляет фразу в историю 
- Обновляет интерфейс и сохраняет данные
#### ```clearPhrases()```
Очищает историю сгенерированных фраз после подтверждения пользователя
#### ```openAddWordsDialog()```
Открывает диалоговое окно для добавления новых слов:
- Позволяет выбрать категорию (имя/псевдоним)
- Проверяет на дубликаты
- Сохраняет новые слова с сортировкой 
#### ```showAllPhrases()```
Отображает диалоговое окно со всеми сгенерированными фразами
#### ```openViewWordsDialog()```
Открывает диалоговое окно для просмотра и управления списками слов:
- Вкладки для имен и псевдонимов
- Возможность удаления слов
#### ```createWordsPanel(List<String> words)```
Создает панель для отображения и управления списком слов:
- Отображает список в JList
- Добавляет кнопку для удаления выбранных слов
#### ```resolveDataDir()```
Определяет папку, в которой хранятся `data.json` и `phrases.json`
#### ```importWords()``` / ```exportWords()``` / ```exportPhrases()```
Импорт и экспорт списков слов (JSON) и сохранение истории фраз в текстовый файл
#### ```copyCurrentPhrase()```
Копирует текущую фразу в буфер обмена
#### ```createStyledButton(String text)```
Создает стилизованную кнопку с заданным текстом

## Формат данных
Файл ```data.json``` сохраняется в следующем формате: </br>
```
{
  "names": [
    "Имя1",
    "Имя2",
    ...
  ],
  "nicknames": [
    "Псевдоним1",
    "Псевдоним2",
    ...
  ]
}
```
Файл ```phrases.json``` сохраняется в следующем формате: </br>
```
{
  "generatedPhrases": [
    "Фраза1",
    "Фраза2",
    ...
  ]
}
```

## Инструкция по использованию
1. Генерация фразы: Нажмите кнопку "Сгенерировать фразу" для создания новой уникальной комбинации.
2. Добавление слов: Используйте кнопку "Добавить новые слова" для расширения базы имен и псевдонимов.
3. Просмотр слов: Кнопка "Просмотреть все слова" позволяет увидеть текущие списки имен и псевдонимов.
4. Просмотр фраз: Кнопка "Просмотреть все фразы" показывает историю всех сгенерированных комбинаций.
5. Копирование: Кнопка "Скопировать фразу" копирует текущую фразу в буфер обмена.

## Где хранятся данные
- Если в папке, из которой запущена программа, есть `data.json` (запуск из папки проекта) — используются `data.json` и `phrases.json` из этой папки.
- Иначе (обычный запуск `NameGenerator.exe`) данные лежат в папке пользователя: `%APPDATA%\NameGeneratorApp` в Windows, `~/.namegeneratorapp` в Linux/macOS. При первом запуске туда копируется стандартный набор слов, встроенный в программу.
- Файлы читаются и записываются в кодировке UTF-8. Повреждённый файл не удаляется, а сохраняется рядом с расширением `.bak`.

## Импорт и экспорт
- «Просмотреть все слова» → «Экспорт...» сохраняет имена и псевдонимы в JSON-файл того же формата, что и `data.json`.
- «Просмотреть все слова» → «Импорт...» добавляет слова из такого файла к существующим, дубликаты пропускаются.
- «Просмотреть все фразы» → «Сохранить в файл...» сохраняет историю фраз в текстовый файл.

## Требования
- Для запуска готового `NameGenerator.exe` ничего устанавливать не нужно — Java встроена в сборку
- Для запуска из исходников: Java 8 или новее и библиотека json-simple-1.1.1.jar
- Для сборки `.exe`: Windows и JDK 17 или новее (нужна утилита `jpackage`)

## Сборка .exe (Windows)
1. Установите JDK 17+ (например, [Temurin](https://adoptium.net)) и убедитесь, что `jpackage --version` работает в командной строке.
2. Запустите в папке проекта:
``` build.bat ```
3. Готовая программа появится в папке `dist\NameGenerator`. Запускается файлом `NameGenerator.exe`; распространять нужно всю папку целиком (в ней лежит встроенная Java).

Чтобы дополнительно получить установщик `dist\NameGenerator-1.0.0.exe` (ярлыки в меню «Пуск» и на рабочем столе), установите [WiX Toolset 3](https://wixtoolset.org) и запустите:
``` build.bat installer ```

Без Windows `.exe` можно получить через GitHub Actions: workflow `Build Windows EXE` запускается при push в `main` (или вручную на вкладке Actions) и прикладывает архив `NameGenerator-windows` к запуску.

## Сборка и запуск из исходников
1. Компиляция
``` javac -encoding UTF-8 -cp "lib/json-simple-1.1.1.jar" src/NameGeneratorApp.java -d bin ```
2. Запуск (Windows)
``` java -cp "bin;lib/json-simple-1.1.1.jar" NameGeneratorApp ```
Запуск (Linux/macOS)
``` java -cp "bin:lib/json-simple-1.1.1.jar" NameGeneratorApp ```

В Linux/macOS можно использовать скрипт `./build.sh run`.

## Особенности реализации
- Использует Swing для графического интерфейса
- Сохраняет данные в JSON-формате (UTF-8)
- Автоматически создает файл данных при первом запуске
- Поддерживает кириллические символы
- Имеет обработку ошибок при загрузке/сохранении данных
- Старается не повторять фразы, которые уже есть в истории
